FAQ

Everything you need to know
What can I do with Thuna?

You can compress files, convert common formats, merge PDFs and images, and manage your recent results from one simple workspace.

Do I need to create an account?

No. Thuna works without an account, so you can upload a file and process it immediately.

Which file formats are supported?

Thuna supports common image, document, archive, audio, and video formats. The available output formats are shown in the format picker for each tool.

Are my files kept private?

Processed files are session-based and temporary. They are not intended to be permanent storage, so download anything you want to keep.

Can I use Thuna on my phone?

Yes. The interface is responsive and adapts to smaller screens, so the tools work on mobile and desktop browsers.
